NEVER create a pull request, push a branch, or perform other "writes" to the external world without asking for permission, even when in "auto mode".

## Editing plans and specs

When revising a plan or spec, rewrite relevant parts to state only the current decision, as if it had always been the plan. Drop superseded context, comparisons to it, and evidence behind the changes unless it is imperative to the implementation. If a line only makes sense as a delta from a prior version, it's a vestige, so cut it.
